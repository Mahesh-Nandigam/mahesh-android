# 🛡️ Google Play Prominent Disclosure: Accessibility Service

### Mahesh- Accessibility Usage Declaration

**Mahesh-** uses the Android `AccessibilityService` API strictly to enable user-requested, hands-free automation features.

#### Explicit Usage Scope:
1. **Hands-Free Messaging:** Automatically enters text into messaging apps (such as WhatsApp) and taps the send button when directed by the user's voice command.
2. **Hands-Free Navigation:** Opens and navigates user-directed app menus when the user is driving, walking, or unable to touch the screen.

#### What Mahesh Does NOT Do:
* **Zero Data Collection:** Mahesh does **NOT** read, record, store, or transmit your private chats, passwords, keystrokes, or screen content.
* **No Background Spying:** The Accessibility Service is only activated in direct response to an explicit voice command from the user.
* **No Financial Automation:** Mahesh automatically halts automation if a payment PIN, biometric prompt, or password entry field is detected.

*Compliant with Google Play Developer Policy on AccessibilityService APIs.*
